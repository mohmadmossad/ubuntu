# نظام المحاسبة الشامل

## وصف المشروع

نظام محاسبة شامل ومتكامل مصمم للشركات الصغيرة والمتوسطة، يوفر جميع الأدوات اللازمة لإدارة العمليات المحاسبية والمالية بكفاءة عالية.

## الميزات الرئيسية

### 🔐 إدارة المستخدمين والصلاحيات
- نظام تسجيل دخول آمن
- إدارة المستخدمين مع صلاحيات مخصصة
- تحكم دقيق في الوصول لكل وحدة

### 📦 إدارة المخازن والأصناف
- إضافة وتعديل الأصناف
- توليد وطباعة الباركود

- تتبع حركة المخزون
- تنبيهات إعادة الطلب

### 🛒 إدارة المشتريات
- فواتير المشتريات النقدية والآجلة
- الدفع الجزئي
- مردودات المشتريات
- نظام خصومات متقدم

### 💰 إدارة المبيعات
- فواتير المبيعات النقدية والآجلة
- طباعة ومشاركة الفواتير
- مردودات المبيعات
- تتبع المدفوعات

### 👥 إدارة العملاء والموردين
- قاعدة بيانات شاملة للعملاء والموردين
- كشوفات حساب تفصيلية
- سندات القبض والصرف
- تتبع الأرصدة

### 💸 إدارة المصروفات
- تسجيل وتصنيف المصروفات
- تقارير مصروفات مفصلة
- ربط المصروفات بالحسابات

### 📊 النظام المحاسبي
- دليل محاسبي قابل للتخصيص
- الميزانية العمومية
- قائمة الأرباح والخسائر
- تقارير مالية شاملة

### 💳 إدارة الصناديق
- صناديق منفصلة لكل مستخدم
- تصفية الصناديق
- تتبع حركة النقد

## التقنيات المستخدمة

### الواجهة الخلفية (Backend)
- **Flask** - إطار عمل Python
- **SQLAlchemy** - ORM لقاعدة البيانات
- **Flask-JWT-Extended** - المصادقة والتوكينات
- **PostgreSQL** - قاعدة البيانات (الإنتاج)
- **SQLite** - قاعدة البيانات (التطوير)

### الواجهة الأمامية (Frontend)
- **React** - مكتبة JavaScript
- **Vite** - أداة البناء
- **Tailwind CSS** - إطار عمل CSS
- **shadcn/ui** - مكونات UI
- **Lucide React** - الأيقونات
- **Recharts** - الرسوم البيانية

## متطلبات التشغيل

### للتطوير المحلي
- Python 3.11+
- Node.js 18+
- npm أو yarn

### للإنتاج
- خادم يدعم Python
- قاعدة بيانات PostgreSQL
- خدمة استضافة ويب

## التثبيت والتشغيل

### 1. استنساخ المشروع
```bash
git clone <repository-url>
cd accounting_app
```

### 2. إعداد البيئة الافتراضية
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# أو
venv\Scripts\activate     # Windows
```

### 3. تثبيت التبعيات
```bash
# Python dependencies
pip install -r requirements.txt

# Node.js dependencies
npm install
```

### 4. إعداد المتغيرات البيئية
```bash
cp .env.example .env
# قم بتعديل ملف .env بالقيم المناسبة
```

### 5. إعداد قاعدة البيانات
```bash
flask db init
flask db migrate -m "Initial migration"
flask db upgrade
```

### 6. بناء الواجهة الأمامية
```bash
npm run build
```

### 7. تشغيل التطبيق
```bash
python main.py
```
