# تصميم قاعدة البيانات (ERD)

## 1. المستخدمون والصلاحيات

### جدول `Users`
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `user_id`     | INT (PK)   | معرف المستخدم (مفتاح أساسي)             |
| `username`    | VARCHAR(50)| اسم المستخدم (فريد)                     |
| `password_hash`| VARCHAR(255)| كلمة المرور المشفرة                    |
| `email`       | VARCHAR(100)| البريد الإلكتروني (فريد)                |
| `full_name`   | VARCHAR(100)| الاسم الكامل للمستخدم                   |
| `is_active`   | BOOLEAN    | هل الحساب نشط؟                         |
| `created_at`  | DATETIME   | تاريخ إنشاء الحساب                     |
| `updated_at`  | DATETIME   | تاريخ آخر تحديث للحساب                 |

### جدول `Roles`
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `role_id`     | INT (PK)   | معرف الدور (مفتاح أساسي)                |
| `role_name`   | VARCHAR(50)| اسم الدور (مثال: Admin, Accountant)    |

### جدول `UserRoles` (جدول وسيط للعلاقة Many-to-Many)
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `user_id`     | INT (FK)   | معرف المستخدم                          |
| `role_id`     | INT (FK)   | معرف الدور                             |

### جدول `Permissions`
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `permission_id`| INT (PK)   | معرف الصلاحية (مفتاح أساسي)             |
| `permission_name`| VARCHAR(100)| اسم الصلاحية (مثال: create_invoice)   |

### جدول `RolePermissions` (جدول وسيط للعلاقة Many-to-Many)
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `role_id`     | INT (FK)   | معرف الدور                             |
| `permission_id`| INT (FK)   | معرف الصلاحية                          |

## 2. المخازن والأصناف

### جدول `Warehouses`
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `warehouse_id`| INT (PK)   | معرف المخزن (مفتاح أساسي)               |
| `name`        | VARCHAR(100)| اسم المخزن                             |
| `location`    | VARCHAR(255)| موقع المخزن                            |

### جدول `Categories`
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `category_id` | INT (PK)   | معرف الفئة (مفتاح أساسي)                |
| `name`        | VARCHAR(100)| اسم الفئة                             |
| `parent_id`   | INT (FK)   | معرف الفئة الأم (للفئات الفرعية)        |

### جدول `Units`
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `unit_id`     | INT (PK)   | معرف الوحدة (مفتاح أساسي)               |
| `name`        | VARCHAR(50)| اسم الوحدة (مثال: قطعة، كرتون)         |
| `conversion_factor`| DECIMAL(10,4)| عامل التحويل للوحدة الأساسية         |

### جدول `Products`
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `product_id`  | INT (PK)   | معرف الصنف (مفتاح أساسي)                |
| `name`        | VARCHAR(255)| اسم الصنف                             |
| `description` | TEXT       | وصف الصنف                              |
| `barcode`     | VARCHAR(50)| باركود الصنف (فريد)                    |
| `purchase_price`| DECIMAL(10,2)| سعر الشراء                            |
| `sale_price`  | DECIMAL(10,2)| سعر البيع                             |
| `category_id` | INT (FK)   | معرف الفئة                             |
| `base_unit_id`| INT (FK)   | معرف الوحدة الأساسية                   |
| `reorder_level`| INT        | مستوى إعادة الطلب                      |

### جدول `Inventory`
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `inventory_id`| INT (PK)   | معرف المخزون (مفتاح أساسي)              |
| `product_id`  | INT (FK)   | معرف الصنف                             |
| `warehouse_id`| INT (FK)   | معرف المخزن                            |
| `quantity`    | DECIMAL(10,2)| الكمية الحالية                         |
| `last_updated`| DATETIME   | تاريخ آخر تحديث                       |

### جدول `InventoryMovements`
| الحقل         | النوع       | الوصف                                 |
|---------------|------------|---------------------------------------|
| `movement_id` | INT (PK)   | معرف الحركة (مفتاح أساسي)               |
| `product_id`  | INT (FK)   | معرف الصنف                             |
| `warehouse_id`| INT (FK)   | معرف المخزن                            |
| `movement_type`| VARCHAR(50)| نوع الحركة (مثال: In, Out, Transfer)  |
| `quantity`    | DECIMAL(10,2)| الكمية المتحركة                        |
| `movement_date`| DATETIME   | تاريخ الحركة                           |
| `user_id`     | INT (FK)   | المستخدم الذي أجرى الحركة              |
